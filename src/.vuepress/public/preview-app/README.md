# Web preview assets

Static assets behind `/preview/` and `/zh/preview/`. The page embeds
`index.html` in an iframe; the frame decodes a `.tsfile` with a WebAssembly
build of the TsFile C++ reader.

| File | Origin |
|------|--------|
| `index.html` | Hand-written |
| `app.js` | Hand-written |
| `tsfile.js` | Generated by Emscripten |
| `tsfile.wasm` | Generated by Emscripten |
| `sample.tsfile` | Fixture for the "Load sample data" button |

## Regenerating the WebAssembly build

The reader is compiled from the C++ SDK sources, so the build lives in the
main repository under `cpp/wasm/`. Do not edit `tsfile.js` or `tsfile.wasm`
by hand; rebuild and copy the results over:

```bash
git clone https://github.com/apache/tsfile.git
cd tsfile/cpp && bash wasm/build.sh
cp build/demo/tsfile.js build/demo/tsfile.wasm \
   <website>/src/.vuepress/public/preview-app/
```

The build requires the Emscripten SDK (`emcmake`). See `cpp/wasm/build.sh`
for the exact configuration flags.
